# YouTube Exercise Clone

This project is a clean and responsive HTML and CSS implementation of the YouTube homepage interface[cite: 1]. 

## Features

* **Fixed Top Navigation Bar:** Includes a hamburger menu icon, YouTube logo, search bar, voice search button, and right-section user tools (upload button, app grid, notifications badge, and user avatar)[cite: 1].
* **Persistent Sidebar:** Features sidebar links with icons for Home, Explore, Subscriptions, Originals, YouTube Music, and Library[cite: 1].
* **Responsive Video Grid:** Utilizes CSS Grid and media queries to switch between multi-column layouts based on screen size[cite: 1].
* **Interactive Video Cards:** Each card features a video thumbnail with a timestamp overlay, channel profile picture, video title, author name, and view/time statistics linked directly to YouTube[cite: 1].

## Technologies Used

* **HTML5** for structure[cite: 1]
* **CSS3** (Flexbox, CSS Grid, and Media Queries) for styling and layout[cite: 1]
* **Google Fonts (Roboto)** for typography[cite: 1]

## How to Run Locally

1. Save the source code into a file named `index.html`[cite: 1].
2. Double-click the file or open it using any modern web browser (Chrome, Firefox, Edge, Safari) to view the clone[cite: 1].
